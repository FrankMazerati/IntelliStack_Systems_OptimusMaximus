MAXIMUS OPTIMUS COMMAND CENTER — REFRESHED HTML

CONTENTS
- index.html: redesigned responsive landing/login concept
- command-center-home.png: background artwork referenced by index.html

HOW TO OPEN
1. Extract this ZIP to a folder.
2. Keep index.html and command-center-home.png together in the same folder.
3. Open index.html in a modern browser.

DESIGN
Blue / white / steel-gray / black palette; Space Grotesk, Inter, DM Sans, Playfair Display Italic, and Caveat script font stacks. Online Google Fonts are used when available; system fallbacks remain.

IMPORTANT
This is a front-end prototype. The buttons and account-mode controls respond in the browser, but no real authentication, email delivery, password reset, SSO, company membership validation, or Supabase authorization is connected by this HTML alone. The role selector is a visual choice only and must never grant permissions. Validate identity, tenant membership, and role permissions server-side through Supabase policies/functions before production.
